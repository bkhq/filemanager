## Context

- `registry/fm/react/preview-registry.ts`: built-in previewers matched by `kindOf` (17-33); `findPreviewer` (47); plugins add previewers (`FmPlugin.previewers`).
- `registry/fm/react/previewers.tsx`: `PdfPreview` (40) uses an iframe; `FallbackPreview` (44).
- `registry/fm/react/state.ts` `kindOf` decides by MIME / extension only, so extensionless text files fall back to download.
- Existing plugin to mirror: `registry/fm/plugins/sheet.ts`, `sheet-view.tsx`, registry item `fm-plugin-sheet`.
- Reference: bkd `MarkdownRenderer.tsx` + `ShikiCodeBlock.tsx`, rendered / source toggle; bks `file-content.tsx` (`#toolbar=0&navpanes=0` on PDFs, binary sniff).

## Proposal

- A7: `PdfPreview` appends `#toolbar=0&navpanes=0`; download stays in the header.
- B1: for files whose kind is not decided by MIME / extension (`other`, or no extension) and size ≤ 2 MiB, the previewer reads bytes 0-8191 (Range) and opens the text editor when there is no NUL byte, else the download fallback. Implemented as a sniffing previewer wrapper; pure `looksBinary(bytes)` helper with unit tests.
- B5: new optional registry item `fm-plugin-markdown` (`registry/fm/plugins/markdown.ts` + view): previewer for `.md` / `.markdown` with a Rendered / Source toggle in the header (source = the existing text editor, so editing, drafts and save still work); GFM tables / task lists; code blocks highlighted. Dependencies: a maintained Markdown renderer and highlighter at their latest versions (e.g. `react-markdown` + `remark-gfm`, highlighting via `shiki` or the renderer's plugin); verify with `npm view`, add exact versions to the plugin item and to `apps/fm-web`. Links render safely (no raw HTML).
- fm-web demo enables the Markdown plugin; README documents the plugin.

## Acceptance

- Unit tests: `looksBinary`; Markdown plugin match.
- e2e: an extensionless text file opens in the editor (seed one in fm-api `seed.ts`, e.g. `notes/LICENSE`); README.md shows rendered Markdown and can switch to source; PDF iframe src carries `#toolbar=0`.
- `bun run check`, the e2e suite and `registry:smoke` pass.
