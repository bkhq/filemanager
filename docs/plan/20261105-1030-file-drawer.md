## Context

- Architecture §4 lists `<FileDrawer />` (bkd side panel) next to `<FileManager />` and `<FilePicker />`; only the last two exist.
- bkd (`apps/frontend/src/components/files/FileBrowserDrawer.tsx`) wraps its own `FileBrowserContent` (803 lines) in its own `SidePanel` shell with minimize / fullscreen / close actions and a persisted width. So bkd needs the content without a shell plus a slot for its header buttons; other hosts want a ready-made drawer.
- `<FileManager />` already adapts to narrow containers (< `NARROW` px: tree or open file stacked with a back button) but has no slot for host buttons and always draws its own card border.

## Proposal

1. `<FileManager headerActions={…}>`: host buttons at the right end of the main header (all layouts, also in the stacked tree view).
2. `react/file-drawer.tsx`:
   - `FileDrawerContent` — `FileManager` preset for side panels: split (explorer) layout, no outer border / radius, fills its parent; every `FileManager` prop passes through (`mounts` via the router, `initialMount` / `initialPath`, `readOnly`, `features`, `plugins`, `meta`, `headerActions`). For hosts with their own panel (bkd).
   - `FileDrawer` — the same inside a right-hand shadcn `Sheet`: `open` / `onOpenChange`, drag handle on the left edge to resize (min 360 px, max 90 % of the viewport, width persisted under `storageKey`), a fullscreen toggle, Esc / close button; full screen on phones.
3. Registry: both in `fm-react` (adds the `sheet` registry dependency). Demo: "Open drawer" button in the fm-web header. README section.

## Risks

- Two `FileManager` instances (page + drawer) in the demo share `storageKey` preferences; the drawer gets its own default key (`fm-drawer`).
- Sheet focus trap vs. CodeMirror / dialogs inside: covered by e2e (edit and save inside the drawer, open a preview dialog from it).

## Scope

`registry/fm/react/file-manager.tsx` (slot), new `react/file-drawer.tsx`, labels, `registry.json`, `apps/fm-web` (sheet component, demo button), README, e2e.

## Verification

`bun run check`, `registry:smoke`; e2e: open the drawer, browse and open a file, edit + save, resize (width persists after reload), fullscreen toggle, Esc closes; `headerActions` render in the header; phone viewport opens full screen.
