## Proposal

- A1: `Ctrl/Cmd+S` saves when dirty (inside the editor and its pane); the header shows an "Unsaved" marker while dirty; a "More" menu offers "Discard changes".
- A2: word-wrap toggle in the header (icon button, `aria-pressed`), persisted in localStorage (`fm:wrap`, or the host `storageKey` when available through props / context).
- B2: text files above the limit open read-only with only the first `MAX_TEXT_BYTES` loaded (Range request) and a banner "Large file: showing the first N MB, read-only"; download stays available.
- B3: on 412 the banner offers three actions: Overwrite (save without If-Match), Reload from disk (drop the draft), Keep editing (dismiss).
- B4: drafts persist per `mount + path` in localStorage (bounded, e.g. 50 entries / 5 MiB total, oldest dropped) with the etag they were based on; reopening a file restores its draft and marks it dirty; if the file's etag changed meanwhile, the B3 banner appears before saving. Drafts are dropped on save, discard, delete and rename of the file (the shell calls a small exported `clearDrafts(mount, pathPrefix)`).
