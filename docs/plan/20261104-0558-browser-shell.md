## Proposal

- A3: entry menu gains "Copy path" (the mount-relative path, e.g. `/notes/todo.txt`) and "Copy name"; confirmation via the existing notice.
- A4: right-click on a folder or mount row (tree) and on a folder row (list) offers "New file here", "New folder here", "Upload here", targeting that folder without navigating first (dialogs and the upload queue take an explicit target folder).
- A5: tree toolbar "Collapse all": expansion moves into a set owned by `FileManager` (keys `mount:path`), nodes read it; auto-expansion of the current path keeps working.
- B7: remember the last mount, folder and open file under `\${storageKey}:last`; restore on mount unless `initialMount` / `initialPath` are given; ignore entries that no longer exist.
- B8: narrow containers in the split layout show either the tree or the preview, with a back button to the tree (bks style) instead of switching to the list; the list layout stays for `layout="single"`.
