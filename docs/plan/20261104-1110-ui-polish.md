## Context

- `file-list.tsx` is virtualized (`@tanstack/react-virtual`); selection is click / Ctrl / Shift only. Row `onDragStart` sets only the internal `DRAG_TYPE` payload.
- `file-tree.tsx` renders nested shadcn `Collapsible` branches; every loaded row is in the DOM. Keyboard nav (`onTreeKeyDown`) walks DOM treeitems; tests use nested `role=group` for driver sections.
- Uploads: react-dropzone with `noPaste` (paste was turned off to keep behaviour unchanged).
- `media-stage.tsx`: zoom / fit / rotate / flip buttons, no keys.
- CodeMirror language data is already loaded per file (`LanguageDescription.load()` → one chunk per language); `TextPreview` is lazy. Remaining Vite warning: main chunk ~672 kB, Markdown plugin chunk ~708 kB.
- CI (`ci.yml`): `oven-sh/setup-bun@v2` unpinned in 3 jobs (one job pinned by SHA), `runs-on: ubuntu-latest`, actionlint SC2034 (unused `i` in the S3 wait loop).

## Proposal

1. **Marquee selection** (list and grid): pointer-down on empty list space draws a rectangle; rows intersecting it are selected (computed from virtual row offsets / grid columns, so off-screen rows count); Ctrl/Cmd adds to the selection; auto-scroll near the top / bottom edge; Esc cancels. Click on empty space still clears.
2. **Virtualized tree**: flatten visible rows (mounts, expanded folders via cached listings, trash rows, driver groups) into `{ key, depth, kind }` and render with `useVirtualizer`; rows keep `role=treeitem` with `aria-level` / `aria-expanded` / `aria-selected`, indent by depth. Collapsible is dropped (no animation). Keyboard nav, context menus, drag/drop, reveal-on-refresh (scroll by index) keep working; driver groups become level-1 rows (tests switch from `role=group` to `aria-level`).
3. **Drag out to desktop**: dragging a single file row (list and tree) also sets `DownloadURL` (`mime:name:absolute download URL`) — Chromium saves the file on drop; other browsers ignore it.
4. **Paste upload**: Ctrl/Cmd+V with files on the clipboard (screenshots, files copied in the OS) uploads to the current folder when focus is in the manager and not in a text field; text paste and the internal cut / copy paste keep working.
5. **Image keys** in the preview: `+` / `-` zoom, `0` fit, `R` / `Shift+R` rotate, `F` flip — only while an image is shown and focus is not in a field.
6. **Bundle**: inspect the two large chunks; lazy-load what dominates (e.g. shiki themes / mermaid in streamdown if not already split); otherwise set `chunkSizeWarningLimit` with a comment. No behaviour change.
7. **CI**: pin `oven-sh/setup-bun` by SHA in all jobs, `runs-on: ubuntu-24.04`, fix SC2034.

## Risks

- Tree virtualization is the largest change (new row model, a11y, keyboard, scroll restore). Mitigation: existing tree e2e suite + a 2 000-entry folder test asserting only a window of rows is rendered.
- Marquee vs. row drag: drag starts only on rows, marquee only on empty space.
- `DownloadURL` needs an absolute, cookie-authenticated URL; hosts with header auth get a failed download (documented).

## Scope

`registry/fm/react/file-list.tsx`, `file-tree.tsx`, `file-manager.tsx`, `media-stage.tsx`, `client/client.ts` (download URL helper if missing), labels, `apps/fm-web/vite.config.ts`, `.github/workflows/*.yml`, e2e, changelog.

## As built

- Marquee (`file-list.tsx`): pointer-down on empty list space (not touch, not on a row); hits computed from row / cell geometry so off-screen rows count; Ctrl/Cmd keeps the previous selection; edge auto-scroll; Esc restores; the click ending a drag does not clear. Off in single-pick mode (`onSelectPaths` absent).
- Tree (`file-tree.tsx`): flattened rows (`group` / `mount` / `dir` / `file` / `trash`) virtualized in the sidebar scroll container (`scrollRef`), `FolderLoader` per open folder fetches every page; `aria-level`, `aria-expanded`, `aria-selected`; index-based keyboard nav with scroll-to-row; reveal via `revealTick`. Collapsible no longer used by the tree. Driver groups are level-1 rows (test updated).
- Drag out: `setDownloadUrl` (`drop.ts`) sets `DownloadURL` on single-file drags from the list and the tree; list drags now allow `copyMove`.
- Paste upload: root `onPaste` uploads clipboard files to the current folder (not from text fields); Ctrl+V only runs the internal paste when entries were cut / copied, otherwise the native paste event goes through.
- Image keys in `media-stage.tsx`: `+`/`=`, `-`, `0`, `R`, `Shift+R`, `F`, scoped to the preview dialog or the right-side section.
- Bundle: measured with source maps; entry = runtime libs, Markdown chunk = streamdown pipeline, largest lazy chunks = shiki grammars; `chunkSizeWarningLimit: 800` with the numbers in `vite.config.ts`. CodeMirror languages were already per-file chunks.
- CI: `setup-bun` pinned by SHA everywhere, `ubuntu-24.04`, SC2034 fixed; actionlint clean.
- Verified: `bun run check` (244 tests), `registry:smoke`, e2e 68/68 (new: marquee, image keys, paste upload, DownloadURL, 2 000-file tree window + End key).
