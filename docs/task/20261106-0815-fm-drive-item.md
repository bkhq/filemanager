## Description

Hosts that only browse and edit files must not carry drive code. `FileManager` drops the `variant` prop and every drive import; the drive becomes `<DriveManager>` in a new `fm-drive` registry item that depends on `fm-react`. Phase 3 / 4 of the drive work are postponed until the drive is redesigned.
