## Description

Close the most visible operation gaps against Google Drive-style file managers without changing the `Driver` interface.

Acceptance criteria:

- Trash: per-mount opt-in; delete moves to trash, trash can be listed, restored and purged; permanent delete stays available.
- Name filter for the current folder (server-side `q` on list).
- Upload conflicts ask: replace / keep both / skip.
- Undo for delete, move, rename and copy.
- Details panel: name, type, size, modified, path (copyable), folder total size.
- New text file and duplicate.
- Preview: previous / next, image zoom, discard-changes guard.
- `editable={false}` on `<FileManager>` disables in-place text editing.
- Router unit tests and e2e cover each item; `bun run check`, registry smoke and e2e pass.
